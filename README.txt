# 11:11 — صفحة تهنئة بسيطة

## التشغيل
1. فك ضغط الملف.
2. في VS Code، افتح المجلد واستخدم إضافة Live Server لفتح `index.html`؛ تشغيل الصفحة بهذه الطريقة يضمن تحميل الموسيقى والملفات المحلية بشكل صحيح.
3. صورة الغلاف هي `photo1.jpg.jpg`. الضغط عليها يفتح الذكريات واحدة تلو الأخرى داخل نافذة ويبدأ الموسيقى؛ يمكن أيضًا تشغيلها أو إيقافها من زر الموسيقى. قد يمنع المتصفح التشغيل التلقائي حتى أول ضغطة.
4. ملف الموسيقى المستخدم هو `assets/audio/AUDIO-2026-11-11-03-42-50.mp3`. لتبديله، غيّر قيمة `src` في عنصر `bgMusic` داخل `index.html` إلى اسم الملف الجديد.
5. عدّل الرسالة والعناوين مباشرة من `index.html`. لإضافة أو حذف صورة/فيديو من الذكريات، أضف أو احذف السطر الخاص به داخل قائمة `memories` في بداية `<script>`؛ احذف السطر كاملًا واترك الفواصل كما هي. إذا حُذف ملف من المجلد، ستظهر رسالة بدل صورة مكسورة.
6. الفيديوهات تظهر بين الذكريات وتعمل بدون صوت، ولا تُحمّل إلا عند الوصول إليها.
7. سجل الأمنيات يحفظ النصوص في مساحة التخزين المحلية للمتصفح على نفس الجهاز، ولا يرفعها إلى الإنترنت.

## ملاحظات
- الموسيقى لا تعمل تلقائياً؛ الزائر يضغط زر التشغيل بنفسه.
- الصور والصوت اختياريان. إذا لم تضفهما ستظل الصفحة تعمل.
- الأمنيات المحفوظة تظل في المتصفح نفسه، ويمكن حذف أي أمنية من سجل الصفحة.
- تظهر ورود وقلوب منقطة باسم إسراء عند فتح الصفحة، وتتساقط ورود إضافية مع كل تنقّل بين الذكريات.
- لتشغيل الصوت دون قيود فتح الملفات المحلية، افتح المشروع من خلال إضافة Live Server في VS Code بدل فتح `index.html` مباشرة.
- التصميم متجاوب للموبايل والكمبيوتر.
- للنشر كرابط: ارفع المجلد إلى استضافة Static مثل GitHub Pages أو Netlify. إذا أردت أن يكون الرابط خاصاً بكلمة مرور، استخدم استضافة تدعم حماية الوصول؛ GitHub Pages وحده لا يوفر حماية بكلمة مرور للموقع المنشور.
